# Triage labels

Skill roles map directly to tracker states.

| State | Meaning |
| --- | --- |
| needs-triage | Awaiting evaluation |
| needs-info | More information needed |
| ready-for-agent | Fully specified and ready for an agent |
| ready-for-human | Requires human implementation |
| wontfix | Will not be addressed |

In local Markdown, record states as `Status: <state>`.
