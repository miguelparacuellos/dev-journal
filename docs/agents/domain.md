# Domain docs

This project has a single context.

Before exploring the domain:

- Read `CONTEXT.md`.
- Read ADRs in `docs/adr/` relevant to the work.
- If any of these documents are missing, proceed.

Use the terms defined in the glossary.
If you need a concept that is missing, flag the gap for domain-modeling.

If a proposal contradicts an ADR, identify the conflict.
Create the glossary and ADRs when terms or decisions are resolved, respectively.
