# Repository conventions

Use English for all repository content, including documentation, issues, code identifiers, comments, tests, commit messages, and application UI text.

## Agent skills

### Issue tracker

Issues and specifications use local Markdown. Before reading or publishing them, consult `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage states. Before assigning a state, consult `docs/agents/triage-labels.md`.

### Domain docs

This repository has a single context. Before exploring the domain, consult `docs/agents/domain.md`.
